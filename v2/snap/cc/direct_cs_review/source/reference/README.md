# Third-party comparator circuit (not redistributed)

The three-T comparator is the public fold-transversal MSC circuit of K. Sahay *et al.*, *Fold-transversal surface code cultivation*, PRX Quantum **7**, 033006 (2026), at final distance 13.

Obtain the noisy circuit (`fd3_baseline_ckt.stim`, d_final = 13, uniform depolarizing noise with idle faults at p = 1e-3) from the authors' public data release and place it in this folder. All scripts in `v2/gapdec/` and `v2/idle/` read it from here. The transformed results used in the manuscript are archived in `v2/gapdec/runs/` and `v2/*.json`.
