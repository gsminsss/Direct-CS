2. 정확한 logical algebra
======================================================================

Target:

    |CS> = CS|++>.

두 commuting Hermitian Clifford involutions:

    C1 = X_A S_B CZ_AB
    C2 = X_B S_A CZ_AB

(여기서는 logical operator notation; physical Steane convention은 아래 참조.)

성질:

    C1† = C1,  C1^2 = I
    C2† = C2,  C2^2 = I
    [C1,C2] = 0
    C1|CS> = |CS>
    C2|CS> = |CS>

joint outcomes r1,r2 ∈ {+1,-1}에 대해

    a = (1-r1)/2
    b = (1-r2)/2

이면 output branch는

    Z_A^a Z_B^b |CS>

(up to global phase).

즉 모든 ideal branch가 usable하고 Pauli frame으로 흡수된다.

초기 |++>에서 ideal branch probabilities는 동일하지 않다:

    P(++ ) = 5/8
    P(+-) = P(-+) = P(--) = 1/8.

중요:
첫 C1,C2의 joint eigenspace는 branch마다 1차원이다.
따라서 preparation에서 발생한 code-space logical input 변화는
C1,C2 measurement 뒤 최종 branch state로 다시 투영된다.
이 성질이 proof-first preparation simplification의 핵심이다.

3. Logical record code
======================================================================

3.1 Minimal 5-check baseline

기존 sequence:

    C1, C2 | D_mid | C12, C1, C2

where C12=C1C2.

ideal record:

    g5(a,b) = (a,b,a⊕b,a,b)

valid codewords:

    00000
    01101
    10110
    11011

minimum Hamming distance:

    d_record = 3.

4개의 binary messages를 distance 3으로 encode하는 length 5 record는
radius-1 Hamming bound 관점에서 자연스러운 최소 construction.

그러나 CAT7 physical readout multiplicity를 포함하면,
record-bit physical parity flip probability

    q = [1-(1-2p_m)^7]/2

이고 wrong valid record probability:

    P_wrong,5
      = 2 q^3 (1-q)^2 + q^4(1-q)
      = 686 p_m^3 + O(p_m^4).

p_m=1e-3에서 conditional record-only logical error ≈ 6.90e-7.
따라서 5-check는 theorem/minimal baseline으로 유지하되 성능 main으로 쓰지 않는다.


3.2 Main 6-check performance protocol

현재 main sequence:

    C1, C2, C12 | D_mid | C1, C2, C12.

record:

    g6(a,b) = (a,b,a⊕b,a,b,a⊕b).

nonzero pairwise differences:

    101101
    011011
    110110

모두 weight 4:

    d_record = 4.

4 binary codewords를 pairwise distance >=4로 두려면 length 5는 불가능:
각 coordinate가 6 pair distance sum에 최대 4만 기여하므로
5 coordinates 총합 <=20.
하지만 6 pairs 모두 distance >=4이면 합 >=24.
따라서 length 6이 최소.

wrong-record probability:

    P_wrong,6
      = 3 q^4(1-q)^2
      = 7203 p_m^4 + O(p_m^5).

p_m=1e-3:
    ≈ 7.23e-9.

즉 5-check 대비 약 95배 감소.
6-check는 overall d_f를 4로 올리기 위한 것이 아니라
큰 record-readout O(p^3) coefficient를 제거하기 위한 performance optimization이다.

4. Steane convention과 physical coordinate operators
======================================================================

Steane logical convention:

    X_L = X^{⊗7}
    Z_L = Z^{⊗7}.

표준 codeword phase convention에서:

    S^{⊗7} = S_L†
    (S†)^{⊗7} = S_L.

따라서 logical checks를 coordinate-wise 만들기 위한 physical operators:

    c1 = X_A S_B† CZ_AB
    c2 = S_A† X_B CZ_AB

and

    c12 = c1 c2
        = H_-^(A) H_-^(B),

where

    H_- = (X-Y)/sqrt(2).

Logical level에서는 C1C2가 H_+⊗H_+ 형태와 연결된다
(physical/logical S orientation 차이에 주의).

5. Explicit Q_k compilation
======================================================================

K = H S  (matrix convention; chronological implementation은 S 후 H).

Exact identities:

    c_k = Q_k (H⊗H) Q_k†.

한 가능한 explicit choice:

    Q1 = (I⊗K) CX_{A->B} (K⊗I)
    Q2 = (K⊗I) CX_{B->A} (I⊗K)
    Q12 = K⊗K.

c1,c2는 entangling operator이므로 local Q만으로는 만들 수 없다.
Q1,Q2의 1개의 entangling CX는 이 의미에서 최소.
Q12는 product operator라 entangling Q가 필요 없다.

6. Native 3Q primitive: iToffoli가 아니라 CZZ
======================================================================

필요한 controlled target primitive:

    G_* = C(H⊗H)
        = |0><0|_a ⊗ I
          + |1><1|_a ⊗ H_A H_B.

CZZ:

    CZZ
      = |0><0|_a ⊗ I
        + |1><1|_a ⊗ Z_A Z_B.

R = R_y(pi/4) 이면

    R Z R† = H.

따라서

    G_*
      = (I_a⊗R_A R_B)
        CZZ
        (I_a⊗R_A† R_B†).

즉 one native/efficient CZZ + local rotations으로 exact implementation 가능.

주의:
iToffoli와 G_*는 spectrum이 달라 단순 unitary conjugation으로 동일해지지 않는다.
따라서 "native iToffoli CS cultivation"이라는 표현은 사용하지 않는다.

권장 표현:
    native-CZZ-assisted direct-|CS> cultivation
또는
    cultivation based on a native or efficiently synthesized C(H⊗H)-class 3Q interaction.
